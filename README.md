# Brevo Clone

A full-stack email marketing and CRM application featuring contact management, campaign analytics, mailing list management, and customizable templates built with Express, Prisma, TiDB/MySQL, and React.

## Features
- **Contact & List Management**: Import, filter, and organize contacts across dynamic lists and segments.
- **Campaign Analytics**: Track email campaign delivery, open, click, and bounce metrics.
- **Email & Template Builder**: Interactive editor for rich email campaign creation.
- **Backend API**: Express API with Prisma ORM database connection.
